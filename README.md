# 🎬 App Películas

Aplicación web desarrollada con **React + Vite** para gestionar un catálogo de películas.

## 🚀 Funcionalidades

- Visualizar películas.
- Agregar nuevas películas.
- Marcar películas como **favoritas**.
- Marcar películas como **"No me gustan"**.
- Filtrar películas por categoría.
- Diseño responsivo para diferentes dispositivos.

## 🛠️ Tecnologías

- React
- Vite
- JavaScript
- Material UI
- CSS

## 📁 Estructura

```text
src/
├── app/
├── features/
│   └── peliculas/

│       ├── models/
│       ├── services/
│       └── data/

├── shared/
├── assets/
├── index.css
└── main.jsx
```

## ▶️ Instalación

```bash
npm install
npm run dev
npm run build
npm run preview
```

La aplicación estará disponible en la dirección indicada por Vite en la terminal.
